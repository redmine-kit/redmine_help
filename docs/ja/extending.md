# ヘルプを足す

<a id="directory-layout"></a>

## ディレクトリの構成

ガイド、プラグインのヘルプ、運用者のディレクトリは、同じ構成です。

```text
index.yml          # サイドバーの章
map.yml            # 画面とトピックの対応(mapping.md)
en/                # 言語ごとのディレクトリ
  <topic>.md       # トピック。1 行目の # の見出しがタイトル
  _support.md      # (運用者だけ)すべてのページに出す囲み
  _support/<topic>.md  # (運用者だけ)1 つのトピックに出す囲み
ja/
  <topic>.md
images/            # トピックが相対のリンクで表示する画像
```

`index.yml` には、章とそのトピックを並べます。トピックは ID だけか、ID とサイドバーの表示名です。表示名は、トピックがユーザーの言語に翻訳されていないあいだ使います(翻訳されたトピックは、その見出しを表示します)。

```yaml
sections:
  - id: support
    title: { en: Support, ja: サポート }
    topics:
      - support/contact
      - { id: support/hours, title: { en: Opening hours, ja: 受付時間 } }
```

ユーザーの言語にないトピックは、英語で、その旨を添えて表示します。

<a id="plugins"></a>

## プラグイン

Redmine のプラグインは、ルートに上の構成の `help/` のディレクトリを置くだけで、ヘルプを足せます。Redmine Help は、インストールされたすべてのプラグインからこれを見つけます。登録は要りません。プラグインの章は、サイドバーでガイドの章のあとに出ます。プラグインの `map.yml` で、プラグインの画面(プラグインのコントローラー)をトピックに対応付けます。トピックは、ガイドのものと重ならないよう、プラグインの名前のディレクトリの下に置きます(たとえば `serverless-ses/sending`)。

<a id="the-operators-directory"></a>

## 運用者のディレクトリ

`REDMINE_HELP_EXTRA_PATH` で、Redmine の外に置いた同じ構成のディレクトリを指定します(たとえば派生のイメージや、マウントしたボリューム)。次のことができます。

- **ページを足す:** 社内の問い合わせ先、ホスティングのサービスのサポートなど、独自のトピックと章を足します。これらの章は、サイドバーの先頭に出ます。
- **ページに囲みを足す:** `<言語>/_support.md` をすべてのページの下に、`<言語>/_support/<topic>.md` を 1 つのトピックの下に出します(ヘルプデスクの番号、社内でのチケットの使い方など)。ユーザーの言語の囲みがないときは、英語の囲みを出します。
- **トピックを置き換える:** ガイドやプラグインと同じパスのトピックは、それを置き換えます。
- **画面を対応付ける:** 運用者の `map.yml` は、プラグインとガイドより先に探します。

<a id="precedence"></a>

## 優先の順

| 対象 | 順(先が優先) |
| --- | --- |
| トピック | 運用者のディレクトリ、プラグイン、ガイド |
| 対応表の画面 | 運用者のディレクトリ、プラグイン、ガイド |
| サイドバーの章 | 運用者のディレクトリ、ガイド、プラグイン(1 つのトピックは 1 回だけ並べる) |
| 囲み | すべてのページの囲み、次にトピックの囲み |
