# Redmine Help

[![CI](https://img.shields.io/github/actions/workflow/status/redmine-kit/redmine_help/ci.yml?branch=main&label=CI)](https://github.com/redmine-kit/redmine_help/actions/workflows/ci.yml)
[![Coverage](https://img.shields.io/codecov/c/github/redmine-kit/redmine_help?label=Coverage)](https://codecov.io/gh/redmine-kit/redmine_help)
[![License](https://img.shields.io/github/license/redmine-kit/redmine_help?label=License)](LICENSE)

Redmine Help (`redmine_help`) is a Redmine plugin that turns the Help link in Redmine's header into help for the current screen, in the user's language. The help is Markdown: the Redmine guide from [redmine-kit/redmine-guide](https://github.com/redmine-kit/redmine-guide), help that other plugins ship in their `help/` directory, and pages an operator adds, such as whom to contact in the company or the support of a hosted service.

[日本語](README.ja.md)

> **Status:** early development (0.1.0). It supports Redmine 7.0 and has been checked with Redmine 7.0.3.
